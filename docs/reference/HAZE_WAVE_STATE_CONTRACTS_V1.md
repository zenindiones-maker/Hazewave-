## HAZE_STATE

`HazeState/v1` carries sonic meaning across three timescales.

Fast:
- energy;
- transient strength;
- spectral centroid;
- spectral flux;
- stereo balance.

Meso:
- tempo;
- beat phase;
- harmonic stability;
- bounded timbre vector.

Macro:
- section identity;
- motif identity;
- track progress;
- long-term intensity.

Every state carries a confidence value.

## WAVE_STATE

`WaveState/v1` is the deterministic visual target derived from a specific HAZE state.

It includes:
- resonance energy;
- HazeMatter regime;
- fracture impulse;
- topology target;
- resonance-walker attractors;
- scar deposition;
- symmetry persistence;
- deterministic seed.

## Contract rule

Internal rendering state may be richer, but the HAZE→WAVE boundary must remain reconstructable from the versioned contract.

A first vertical slice may implement a target-compatible subset rather than the full artistic system.
