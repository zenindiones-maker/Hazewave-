# HAZEWAVE Global Sound History Program v1
## Long-range chronology and volume-generation architecture

## 1. Purpose

The Hazewave Academic Library is designed to move from early-human listening to contemporary and future sound technologies without compressing human history into a short sequence of famous civilizations.

The program must be able to expand indefinitely while remaining navigable.

## 2. Core principle

Chronology is the spine.

Regions, peoples, technologies and musical systems are the branches.

The library therefore uses a **braided chronology**, not one universal ladder.

## 3. Chronology graph

Instead of:

```text
PREHISTORY
→ EGYPT
→ GREECE
→ ROME
→ MIDDLE AGES
→ CLASSICAL
→ MODERN
```

use:

```text
TIME SLICE
├── Africa
├── Southwest Asia
├── South Asia
├── Central/North Asia
├── East Asia
├── Southeast Asia
├── Oceania/Pacific
├── Europe
├── North America
├── Mesoamerica/Caribbean
└── South America
```

Connections are added only when evidence supports contact, transmission, migration, trade, conquest, diaspora, technology transfer or other historical relation.

## 4. Macro phases

These are navigation scaffolds, not claims that every region follows the same sequence.

### PHASE A — EARLY HUMAN SOUND WORLDS
Listening, body, voice, material sound, space, repetition.

### PHASE B — EARLY SOUND-MAKING OBJECTS
Archaeologically visible instruments and resonant objects.

### PHASE C — SETTLEMENT / AGRICULTURE / URBANIZATION
Sound in larger settlements, ritual sites, labor, social differentiation and early institutions.

### PHASE D — EARLY STATES / WRITING / COURTS
Documented instruments, iconography, notation-like systems, court/temple contexts where evidenced.

### PHASE E — REGIONAL CLASSICAL / SACRED / COURT SYSTEMS
Multiple distinct regional traditions.

### PHASE F — TRADE / MIGRATION / EMPIRE / DIASPORA
Transmission, hybridization, forced movement and exchange.

### PHASE G — PRINT / MECHANIZATION / INDUSTRIALIZATION
Music publishing, instrument manufacture, urban publics.

### PHASE H — RECORDED SOUND
Mechanical/electrical recording and reproducible audio.

### PHASE I — BROADCAST / AMPLIFICATION / STUDIO
Radio, microphones, electric instruments, tape, multitrack.

### PHASE J — SYNTHESIS / SAMPLING / ELECTRONIC SYSTEMS
Electronic instruments, studios, dub, hip-hop, dance/electronic practices and sampling.

### PHASE K — DIGITAL / NETWORKED SOUND
MIDI, DAWs, files, internet distribution, software instruments.

### PHASE L — MACHINE LEARNING / GENERATIVE SOUND
Source separation, synthesis, voice conversion, generative music, provenance and authorship.

## 5. Volume-generation matrix

A volume proposal can arise from:

```text
TIME × REGION × TOPIC
```

or

```text
TECHNOLOGY × REGION × SOCIAL CHANGE
```

or

```text
INSTRUMENT × CENTURIES × NETWORK
```

or

```text
REPERTOIRE × COMMUNITY × ARCHIVE
```

The system does not impose a ceiling on volume count.

## 6. Granularity rule

Do not choose 100-year blocks mechanically.

Use historical granularity appropriate to the evidence.

Examples:
- millions/tens of thousands of years for sparse deep-time evidence;
- millennia/centuries for some archaeological periods;
- decades when documents/recordings become denser;
- years/months/days for modern technological events when justified.

Data density controls granularity.

## 7. Civilizational framing

Avoid treating “civilization” as a single self-contained musical box.

For each historical formation investigate:
- internal diversity;
- neighboring communities;
- trade;
- migration;
- conquest;
- religious institutions;
- class/caste/status structures where relevant;
- urban/rural differences;
- instruments;
- performers;
- transmission;
- material technologies;
- archives/evidence.

## 8. Parallel histories

The library should allow simultaneous volumes.

Example:

```text
TIME WINDOW X
├── Volume: Nile Valley sound systems
├── Volume: Mesopotamian instruments/texts
├── Volume: South Asian evidence
├── Volume: East Asian evidence
├── Volume: African regional archaeology
├── Volume: American sound-producing artifacts
└── Comparative synthesis volume
```

The comparative volume comes after strong regional research, not instead of it.

## 9. Influence claims

“Inspired”, “influenced”, “descended from” and “originated in” are high-risk historical verbs.

Every influence claim should identify a mechanism:

- documented contact;
- migration;
- trade;
- teacher/student lineage;
- circulation of instruments;
- circulation of notation;
- recording distribution;
- broadcasting;
- printed media;
- colonial/imperial networks;
- diaspora;
- digital network.

Similarity alone does not prove influence.

## 10. Continuity claims

Do not write:

> “This ancient rhythm survives unchanged today.”

without evidence.

Prefer analysis of:
- documented continuity;
- revival;
- reconstruction;
- transformation;
- recontextualization;
- invented tradition;
- uncertain relationship.

## 12. Contact graph

Historical connections should eventually be machine-readable:

```text
NODE A
→ CONTACT TYPE
→ DATE RANGE
→ EVIDENCE
→ NODE B
```

This supports visualization and guards against invented diffusion stories.

## 13. Research-density map

For every period/region, record:
- evidence density;
- source languages;
- archive accessibility;
- archaeological preservation;
- recording availability;
- specialist coverage;
- uncertainty.

Thin evidence leads to cautious synthesis, not filler.

## 14. Volume proposal gate

A new academic volume requires:
- distinctive research question;
- adequate source base;
- clear relation to existing volumes;
- no redundant scope;
- identified expertise;
- feasible rights/access;
- scholarly value.

## 15. Long-term index

The public website should allow readers to browse by:
- chronological timeline;
- world map;
- people/community;
- instrument;
- technology;
- genre/practice;
- author;
- archive;
- thematic question.

## 16. Relationship to HAZE and WAVE

Every historical research node may generate:

```text
ACADEMIC BOOK
↔ HAZE LISTENING LAB
↔ WAVE MAP / DIAGRAM
↔ NEANDERCAUS EPISODE
↔ WEB ESSAY
↔ EDUCATIONAL PACK
```

But the academic record remains the evidence authority.

## 17. End state

There is no final “last volume”.

As scholarship changes and archives expand, Hazewave can:
- add volumes;
- revise editions;
- create regional corrections;
- publish new source editions;
- extend the chronology into future sound cultures.

The library is a living research system, not a completed encyclopedia.
