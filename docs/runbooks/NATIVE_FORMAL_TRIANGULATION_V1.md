## Scientific model

Three distinct lanes operate on one *source-owned, bounded, immutable ELF*:

1. **REA 6.0.0 / Ghidra 12.1.4:** `rea function <exact-owned-ELF> main --provider ghidra --json`. Existing direct Evidence validates exact ELF SHA256, native provider identity, procedure and assembly. This demonstrates static/native function observation, **not** functional equivalence or recovered original source.
2. **Black-box behavioral synthesis:** compile the original first-party C to ELF; the synthesizer infers one linear-quadratic-linear piecewise candidate from **observed binary input/output only**. It does not read the original C inside the inference function and does not extract source from Ghidra. Candidate C is autogenerated, compiled, executed and checked against the original ELF over all **2,001** integer inputs from **-1000 through 1000**.
3. **Z3 5.1.0.0 formal checker:** compare the inferred candidate **symbolically** against a **separately hand-authored fixture specification** over the same explicit integer domain. UNSAT means no model of the declared mathematical formulas differs in that domain. SAT returns an input and both values. The formal contract is **not inferred from the ELF**, so UNSAT must never be marketed as a mathematical proof of arbitrary binary equivalence.

A passing study records the Ghidra SHA matching the oracle ELF SHA, the generated C SHA, compiled candidate ELF SHA, observed test input/output hash, actual tool version, and Z3 outcome. A deliberate wrong Ghidra SHA is a hard stop; a wrong polynomial/breakpoint yields a machine-checked SAT counterexample. All receipts are private, atomic and mode 0600. No automatic promotion, agent registration, network browser navigation or unknown target input.

## Professional research basis

2026 state-of-the-art directions emphasize **recompilation, executable differential feedback, assembly anchors and behavioral validation**, not just readable decompiled pseudocode. See [PCodeTrans](https://arxiv.org/abs/2603.14855), [ASAP](https://arxiv.org/abs/2610.06900), [Ghidra headless](https://www.ghidradocs.com/12.1.4_PUBLIC/support/analyzeHeadlessREADME.html), [AFL++ advanced fuzzing](https://aflplus.plus/docs/fuzzing_in_depth/) and [Z3 solver tutorial](https://github.com/Z3Prover/z3/tree/master/examples/python).

**Future expansion** by observed qualification, not bulk installation:

- **CEGIS and fuzzing** (AFL++ persistent or libFuzzer): generate hypotheses, retain minimized reproducing input corpus, seek new differential counterexamples, replay before model revision, monitor coverage and time budget. Do not run unbounded fuzzing on the A15 or 2-core Codespace.
- **Z3 bit-vector semantics** when analyzing signed/unsigned machine operations, overflow, arithmetic and shifts. The V1 uses math integers, not bitvectors; numerical safety is separately constrained by the finite ±1000 domain and limited coefficients.
- **Ghidra p-code-based synthesis** only after the prover can bind specific decompiler statements to source hints, handle side effects/global state and independently run recovered functions. The V1 intentionally retains `ghidra_guided_synthesis_proven=false`.
- **Audio/Haze:** real EBU R128 true-peak and integrated LUFS, stems, timbre, dynamics, effects, blind AB tests; FFmpeg's `loudnorm`, `astats` and `ebur128` are distinct analyzers from `volumedetect`. Native deterministic metrics do not prove artistic excellence.
- **Video/Wave:** frame alignment, temporal integrity, color management, high-motion SSIM/PSNR/VMAF where `libvmaf` is available, flow and timeline verification; human art-direction rating remains separate.
- **Iris:** no real sites until kernel-level egress restrictions and fresh browser profile are independently tested; Playwright `route()` by itself is insufficient around redirects, service workers and other subresources.
- **Harness:** one route-specific measured evidence receipt and actual agent `tools/list`+ `tools/call` per capability, with zero-cost admission, sandbox and task grant checks. Unknown cost and unavailable provider remain BLOCKED.
