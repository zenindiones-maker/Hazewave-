# Connected Creative Capabilities

This map records currently available ChatGPT-side capabilities that may assist HAZE/WAVE work. Availability is not expertise and does not grant production authority.

## WAVE — currently available

### Higgsfield
Useful subordinate workflows include:
- motion craft;
- video editing;
- thumbnail generation;
- faceless/hosted video production;
- website building;
- selected UGC production workflows.

Use for bounded production tasks when its workflow matches the mission. Generated output still passes WAVE QC and human review.

### Figma
Useful specialist workflows include:
- design-system/library generation;
- page/screen generation;
- design-to-code;
- motion implementation;
- shaders;
- Code Connect;
- FigJam diagrams.

Figma is a design surface, never Hazewave authority.

### HyperFrames
Useful capabilities include:
- deterministic HTML video compositions;
- GSAP timelines;
- audio-reactive visuals;
- motion/keyframe systems;
- video render/inspect workflows;
- website-to-video capture.

This is especially useful for WAVE and BRIDGE experiments where typed HAZE timing metadata drives deterministic visual behavior.

### Descript
Useful for conversational video/audio post workflows such as transcription-led editing, cleanup, clips and production assembly.

Any audio decision remains HAZE-owned; any visual/editorial decision remains WAVE-owned.

## HAZE — current gap

No connected ChatGPT plugin surfaced as a replacement for deep native REAPER expertise.

That is intentional: HAZE's professional path remains grounded in:
- REAPER runtime and official API;
- ReaScript/JSFX;
- objective audio analysis/QC;
- qualified native-Linux plugins;
- real renders and listening evidence.

External audio helpers may assist research or editing, but they do not substitute for REAPER runtime proof.

## BRIDGE

Suitable shared capabilities:
- HyperFrames audio-reactive visual composition;
- deterministic timeline/marker exchange;
- Figma motion reference when translated into typed implementation;
- video editors only after ownership of audio and visual decisions is explicit.

BRIDGE remains authority=NONE.

## Candidate learning helpers

External learning/discovery plugins may be connected to widen research coverage, but they remain below Tier A official sources.

Examples currently surfaced:
- Acumen by Talarion — current-information gap discovery;
- Udemy — structured expert-course discovery.

Neither may write production policy directly.

## Promotion rule

A connected capability becomes a Hazewave production skill only after:

`CANDIDATE -> PRESSURE_TESTED -> TOOL_VERIFIED -> RUNTIME_PROVEN -> PRODUCTION_SKILL`

For tool-operating skills, pressure tests must include failure/recovery cases, not only happy-path demos.
