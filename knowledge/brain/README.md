## Purpose

Hazewave Brain is the durable knowledge layer for HAZE, WAVE and BRIDGE.

It does not replace the Harness and it never grants execution authority. It exists to make specialist knowledge attributable, versioned, reviewable, fresh, contradiction-aware and reusable across workers.

- **HAZE** owns all audio knowledge and REAPER expertise.
- **WAVE** owns all visual knowledge, including image, video, animation and modern interactive web production.
- **BRIDGE** owns only typed audiovisual translation and synchronization knowledge.

## Truth model

Knowledge moves through independent states:

`DISCOVERED -> SOURCE_VERIFIED -> COMPATIBLE -> RUNTIME_PROVEN -> PRODUCTION_APPROVED -> HUMAN_APPROVED`

A document, model output, tutorial, plugin installation or self-declared expertise never skips those states.

## Source priority

1. Official standards.
2. Official documentation and API references.
3. Official release notes and upstream source.
4. Primary research and recognized professional engineering sources.
5. Professional secondary material.
6. Community discovery.
7. Social/unattributed material only as a lead for verification.

Daily Intelligence has KNOWLEDGE_ONLY authority. Runtime/tool adoption remains:

`DISCOVER -> VERIFY -> SECURITY_REVIEW -> COMPATIBILITY -> BENCHMARK -> RUNTIME_PROOF -> PRODUCTION_APPROVED`

## Brain structure

- `00-Brain/` — operating model, maps and current frontier.
- `10-Haze/` — audio engineering, REAPER, voice, music, mix/master and audio QC.
- `20-Wave/` — image, video, animation, design, WebGPU/web and visual QC.
- `30-Bridge/` — typed audiovisual coordination.
- `40-Sources/` — authoritative source maps and freshness policy.
- `50-Skills/` — competency and skill acquisition maps.
- `60-Human-Review/` — durable preference/rejection evidence templates.
